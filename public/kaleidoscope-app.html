Different questions, same change

Ways to examine the change

Kaleidoscope asks several separate questions of the same before-and-after state. Internally these are called lenses. They do not vote or average disagreement into one score.

Two things can be true at the same time.

A formal legal protection can remain while one enforcement path becomes narrower. Kaleidoscope keeps both facts visible instead of manufacturing one simplified score.

Show the evidence

Evidence and source custody

Kaleidoscope keeps source files, revisions, duplicates, contradictions, and corrections visible. Exact file identity is checked technically so two files are not treated as the same merely because their names look alike.

Evidence files — preserved in the current source record
Silently selected subset — conflicting or inconvenient sources are not silently discarded
Source files inside the runtime — source custody and the running application stay distinct
